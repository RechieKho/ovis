# Lines no reading fits, for `ovis_eval rewrites`: the model may write each
# again in words the compiler reads (a rewrite), and the build is judged by
# what the program prints. `expect: none` means the line should be refused
# (left to the author), not guessed. Held out: not used to write the
# rewrite prompt, so a prompt change is judged by these, not by a few lines.
#
# A case is an `expect:` line (the whole output, one line), then the program,
# then a blank line. Every case has the same first lines:
#   a person has: name, age; winnie is a person; people is a list of winnie.
